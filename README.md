# vibe-blaster

A browser-based top-down shooter for SEIS-606.

## Controls
- Move: Arrow keys or `WASD`
- Fire: `Space` or `K`
- Restart after game over: `Enter`

## Run locally
Open `/home/runner/work/vibe-blaster/vibe-blaster/index.html` in a browser.

## GitHub Pages
This project is static HTML/CSS/JS and can be hosted directly with GitHub Pages.
